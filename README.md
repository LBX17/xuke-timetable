# 序课 · 学期课表

已按提供的两张截图录入 21 条课程安排和 11 节作息。第一周周一为 **2026 年 8 月 31 日**；默认学期 19 周，可在学期设置中修改。

## 使用

- 打开 `index.html` 即可离线使用；部署版可直接通过网页地址访问。
- 整周 / 分日切换；点击周表顶部星期即可查看当天；教学周支持上一周、下一周、直接跳转和回到今天。
- 时钟每秒更新，使用设备时间并转换为北京时间（Asia/Shanghai）。顶部课堂状态始终反映今天，不随所查看的教学周改变。
- 课堂进度 = 已完成授课分钟 / 本堂课总授课分钟。课间休息暂停进度，并显示下一节开始倒计时。
- 根据周次范围、单 / 双周筛选；英语教师 4–11 周为刘红梅，12–19 周为张玲；星期五机械制图的单双周教室分别为 B116、B107。
- 课程卡片可查看和编辑；支持添加 / 删除课程，时间冲突检查，修改节次，导入 / 导出 JSON 备份。
- 修改保存在当前设备当前浏览器，没有跨设备同步。离线文件和在线站点的浏览器数据各自独立。

## 时间表说明

常规第 3–4 节为 10:10–12:00。截图另有错峰说明：1–3 楼 10:05–11:55，4–6 楼 10:20–12:10。

网页识别 B310、B109 等字母加三位数字教室的楼层，并自动应用错峰。两节课内部按常规「50 分钟上课 + 10 分钟课间 + 50 分钟上课」拆分，截图仅给出错峰整体时间；这一拆分是基于常规作息的推定，可在设置中关闭错峰规则。体育「场地待定」等未识别楼层采用常规作息。

时间刻度为常规节次，错峰后的准确起止时间显示在课程卡片上。法定假期和临时调课没有在截图中提供，因此网页按教学周原课表计算。

## 设计与验证

仅保留手机端界面。银灰与白色底色、黑色文字、蓝色强调，单列卡片、底部导航、SVG 实时时钟。采用网页设计工具箱的 GSAP 入场及视图切换动画，支持减少动态效果偏好；GSAP 已本地打包。使用系统字体，不依赖在线字体。首次在线访问后缓存页面资源，支持离线访问；支持通过浏览器添加到手机主屏幕。

已验证教学周日期、单双周筛选、教师切换、错峰教室、上课 / 课间 / 下课边界、北京时间转换与导入数据校验，并检查 320、390、430 像素手机布局。
